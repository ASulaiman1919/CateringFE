# Degi Kitchen Image Sources

Created September 8, 2026 using the built-in OpenAI image-generation tool at the owner's explicit request to try generated food photography again. These are illustrative generated images, not photos of Degi Kitchen orders. The site discloses this under Image notes and uses illustrative image descriptions.

- `kabab-bolani.webp`: original generated composition of grilled chicken kababs, bolani, and chutney on green linen. Source: `exec-5976f17e-a256-492d-84be-0733852353ea.png`.
- `mantoo.webp`: original generated composition of Afghan dumplings on white linen. Source: `exec-051c5da9-319e-4eb2-a855-5169a4eef7b4.png`.
- `bolani.webp`: original generated composition of potato bolani and chutney on white linen. Source: `exec-34af08c2-c023-467a-9c8b-1842a06dd827.png`.

Original PNG files, including their embedded provenance, remain in the owner's Codex generated-images folder. WebP copies are resized and compressed for web delivery. No reference photograph, third-party logo, competitor photograph, or competitor source code was used in these generations.

The additional palaw generation was rejected during visual review because the rice shape was still unsatisfactory. It is not used on the website.
